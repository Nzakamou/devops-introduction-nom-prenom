## Définition du DevOps
Le DevOps est une façon de travailler qui rassemble les développeurs et les administrateurs système. Cela permet de créer des logiciels plus rapidement, de tester le code automatiquement et de corriger les erreurs rapidement sans interrompre le service.

## Commandes Git utilisées
- `git init` : Initialiser le dépôt local
- `git status` : Vérifier l'état des fichiers
- `git add .` : Ajouter les fichiers à la zone de transit (staging area)
- `git commit -m "..."` : Enregistrer les modifications
- `git push` : Envoyer les modifications vers GitHub
